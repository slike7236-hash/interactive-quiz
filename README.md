# Interaktiv Jamoaviy Activity O'yini

Ushbu loyiha guruh va jamoalar uchun mo'ljallangan interaktiv ta'limiy o'yin platformasidir.

## Xususiyatlari:
1. **21 ta Kartochka (Tarot uslubida):** Munajjimlar kartalari shaklidagi interaktiv savol tanlash ekrani.
2. **Moslashuvchan Jamoalar Sozlamasi:** O'yindan oldin 3 ta jamoa nomini kiritish hamda 20 ta turli xil ikonkalardan avatar tanlash imkoniyati.
3. **Mantiqiy Yordam Tizimi (Help):**
   - **Variant (25%):** 4 ta javob varianti va 25% ball beriladi.
   - **Letter (-20% doimiy, har bir ochilgan harf uchun -20%):** Javob harflari sonini ko'rish va 2 tagacha harfni ochish.
   - **20/80 Bo'lishish:** Boshqa jamoalarga tayanish — to'g'ri chiqsa 80% to'g'ri javob berganga, 20% taxmin qilganga.
   - **Check (100%):** To'g'ridan-to'g'ri yordamsiz javob bersa to'liq 100% ball.
4. **Doimiy Pastki Scoreboard:** Har bir sahifada jamoalarning hozirgi ochkolari va navbati ko'rinib turadi.

## GitHub Pages'da ishga tushirish:
1. Ushbu repository'ni GitHub platformasiga yuklang.
2. Repository sozlamalariga (`Settings`) kiring.
3. **Pages** bo'limidan `main` branch'ini tanlab saqlang.
4. Bevosita taqdim etilgan veb-sayt havolasi orqali foydalaning!
